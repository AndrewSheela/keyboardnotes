New song

Set up the track, tempo, and lyric syllables.

1 · Track details

Use a relative path like songs/your-file.mp3 if it's in your songs/ folder next to this file, or a full https://... URL if it's hosted elsewhere.

2 · Lyrics with syllables

Type the lyrics. Split each word into syllables with a hyphen, e.g. A-ma-zing grace how sweet the sound. Put each line on a new line. Click "Build syllable grid" to auto-space them across beats — you can fine-tune timing by tapping in step 3.

3 · Set exact beat for each syllable

Each syllable defaults to one-per-beat. If a syllable actually falls on beat 1, beat 2, or a half-beat like 2.5 (the "&" after beat 2), type that beat number here — the time updates automatically. Beat numbers run continuously through the song (e.g. measure 2 beat 1 in 4/4 = beat 5).

4 · Fine-tune by tapping (optional)

Load the MP3, press play, then tap the button (or hit Space) in rhythm with each syllable. Each tap locks in the exact time for that syllable.
